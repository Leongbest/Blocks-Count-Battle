# Blocks Count Battle

A quick browser game about counting cubes in isometric stacks. Play solo or race a friend on the same screen.

## How to play

1. Open `index.html` in a browser. No installation or account is needed.
2. Choose **Solo** or **Two Players**, then pick a game mode.
3. Count the blocks and submit your answer before the timer runs out. There are five rounds, with 20 seconds per round.

| Mode | What changes |
| --- | --- |
| Classic | The stack stays visible while you count. |
| Memory | The stack slides off screen after five seconds. Count it before it disappears, then answer from memory. |

In Two Players, both players count the same stack. The player with the most correct answers wins; if the score is tied, the lower total response time wins. Each player’s answer is hidden after they submit, then both answers are revealed at the end of the round.

Use the on-screen number pads on desktop or mobile. In Solo, you can also type digits, press **Backspace** to erase a digit or **Delete** to clear the answer, then press **Enter** to submit.

Built with HTML, CSS, JavaScript, and SVG.
